# 🚀 Demarrage rapide - Android Google Play

## 1) Installer les dependances
```bash
npm install
```

## 2) Configurer la monetisation
Modifier:
```
/src/config/monetization.ts
```

## 3) Configurer AdMob App ID
Ajouter l App ID AdMob dans AndroidManifest ou app.json.

## 4) Lancer sur Android
```bash
npx react-native run-android
```

## 5) Tester achats et ads
- Produits Play Billing actifs
- Ads AdMob en mode test

Pret pour la review Google Play.
