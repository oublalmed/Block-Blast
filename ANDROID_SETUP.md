## 🚀 How to Run on Android Emulator

### **Prerequisites**

You need to have installed:
- **Android Studio** (download from https://developer.android.com/studio)
- **Java Development Kit (JDK)** 17 or higher

### **Step 1: Open Android Studio**

```bash
# Open the Android project in Android Studio
npx cap open android
```

This will:
- Launch Android Studio
- Open the `/android` folder as a Gradle project
- Allow you to run the app on an emulator or device

### **Step 2: Run on Emulator**

1. **In Android Studio:**
   - Wait for Gradle sync to complete (bottom status bar)
   - Click the **green play button** ▶️ in the toolbar
   - Select an emulator (or create one if needed)
   - Click **OK** to launch

**OR use the command line:**

```bash
# Run on connected emulator or device
npm run android:run
```

### **Step 3: See Your App!**

Your Block Blast game will launch on the Android emulator as a native app! 🎮

## 📦 Building APK for Distribution

### **Development APK (for testing)**

```bash
# Open Android Studio
npx cap open android

# Then in Android Studio:
# Build > Build Bundle(s) / APK(s) > Build APK(s)

# APK will be in: android/app/build/outputs/apk/debug/app-debug.apk
```

### **Production APK (for Google Play Store)**

```bash
# Open Android Studio
npx cap open android

# Then in Android Studio:
# Build > Generate Signed Bundle / APK
# Follow the wizard to:
# 1. Create a keystore (save it securely!)
# 2. Sign your app
# 3. Build release APK

# Release APK will be in: android/app/build/outputs/apk/release/
```

## 🐛 Troubleshooting

### **Error: "Gradle sync failed"**

**Fix:**
1. Open Android Studio
2. File → Invalidate Caches → Invalidate and Restart
3. Try again

### **Error: "SDK location not found"**

**Fix:**
Create `android/local.properties` file:
```properties
sdk.dir=/path/to/your/Android/Sdk
```

On Windows: `C:\\Users\\YourName\\AppData\\Local\\Android\\Sdk`
On Mac/Linux: `~/Library/Android/sdk` or `~/Android/Sdk`

### **Error: "Command failed: gradlew"**

**Fix:**
```bash
cd android
chmod +x gradlew
./gradlew clean
cd ..
```

### **App shows blank screen**

**Fix:**
1. Make sure you ran `npm run build` first
2. Run `npx cap sync android`
3. Clear app data on emulator
4. Rebuild the app
